Practice guide

Krillion.si Endless practice

Seven prompts per dive. Read the question during the three-second preview, then enter one answer within 25 seconds. Unrecognized answers can be retried. A suggested spelling correction requires a second submission to confirm.

Each category uses preset scores below 50 first valid answers. At 50, observed answer frequencies determine the tiers: 20% or more earns 10 points; 10–20% earns 30; 5–10% earns 60; 2–5% earns 85; below 2% earns 100. Boundaries belong to the lower score tier. Daily snapshots update these frequencies, and each dive locks its scores at the start. Each point moves the dive ten metres. After seven rounds, review every accepted answer or start another dive.

The practice bank has 42 finite categories. Unseen questions come first; the bank reshuffles after it is used. Standard names, common spellings and the aliases allowed by each question are accepted. Short symbols count only where the question says so.

Answer checking runs on your device. Your first accepted canonical answer ID per category is sent to our own anonymous statistics service; rejected inputs and timeouts are not sent. An anonymous browser cookie prevents repeat counting. Clearing cookies can create a new identifier, so samples are approximate. Failed uploads wait in this browser for retry. If statistics cannot load, you can still play with preset scores. Progress is saved in this browser when storage is available. The clock keeps running in background tabs. Opening the game menu pauses it. There is no login, external judge, leaderboard or official score sync.
